Privacy Policy

Last updated: October 29, 2026

Scope: This policy describes Rule & Flow Uploader, a private automation tool operated for the Rule & Flow YouTube channel. It does not offer a public Google sign-in service.

1. What the application does

Rule & Flow Uploader helps the channel owner upload and schedule original videos to YouTube, retrieve the channel's video and performance information, and review reports to improve channel operations.

2. Google and YouTube data accessed

When the channel owner authorizes access, the application uses the YouTube Data API and YouTube Analytics API for the following limited purposes:

  • Video upload permission (youtube.upload): upload videos, set video metadata, and schedule publication on the authorized channel.
  • YouTube read-only permission (youtube.readonly): read the channel identity, video IDs, titles, publication status, and available view, like, and comment counts.
  • YouTube Analytics read-only permission (yt-analytics.readonly): access available performance reports, including views, engaged views, watch time, average viewing duration, subscribers gained, traffic sources, and geographic aggregates.

The tool may also retrieve comments that are publicly accessible through the YouTube Data API. It does not request access to Gmail, Google Drive, Google Contacts, or Google passwords.

3. How the information is used

Data is used only to operate the owner's YouTube channel: publishing and scheduling videos, generating internal performance reports, understanding audience engagement, and checking the outcome of automated jobs. Google user data is not sold, used for ad targeting, or made available as a third-party dataset.

4. Where information is stored and shared

Automation runs using GitHub Actions. OAuth client credentials and refresh tokens are configured in repository secrets rather than published website files. The tool saves channel performance snapshots and any collected comment/analytics records in a separate private GitHub repository accessible to authorized repository collaborators. Data is exchanged with Google APIs to perform the requested operations and processed by GitHub as the automation hosting and storage provider.

This public informational website does not contain YouTube OAuth credentials or private YouTube Analytics reports. When visiting this website, GitHub Pages may process technical request information under GitHub's privacy statement.

5. Retention and deletion

Channel snapshots and automation records are retained while needed for the owner's operational reporting, unless deleted earlier by the owner. The owner can delete retained snapshots from the private GitHub repository and can revoke the application's Google access at any time through Google Account connections. Revocation prevents future authorized API access but does not automatically delete previously saved snapshots or YouTube videos.

6. Security and access

The tool is intended only for operation by the authorized Rule & Flow channel owner. Repository access is managed through GitHub permissions. Credentials should never be posted in public issues, source code, or comments. No security system guarantees absolute protection, and access credentials may be revoked or replaced when necessary.

7. Changes to this policy

This policy may be updated when the automation's permissions or data-handling practices change. The latest version and update date will be published on this page.

8. Contact

For questions or data removal requests, contact the operator via the Rule & Flow website repository. GitHub issues are public: do not include access tokens, private analytics data, or other sensitive information. Requests involving private data should first ask for a secure contact method.

9. Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including applicable Limited Use requirements. YouTube use is also subject to the YouTube Terms of Service and Google Privacy Policy.
